# strict 4+2 最终运行点诊断

本页记录当前 x86/CUDA production 在 89 张 mixed lock 图像上的最终运行点诊断。它由已冻结的 `base_lock_predictions.jsonl`、`specialist_lock_predictions.jsonl` 和对应 YOLO 标签复算，不重新执行模型推理，也不参与 dev 选模。

## 计算口径

- Base 类 0–3 使用最低置信度 `0.01`；新增类 4/5 分别使用 dev 选出的 `0.18/0.08`。
- TP/FP 按图像和类别分别计算，预测框与真值框在 IoU `>=0.50` 时进行一对一匹配。
- 未匹配预测均记为 FP，包括重复框、定位不足、错类和不存在该类别的图像上的检测。
- precision 为 `TP / (TP + FP)`；recall 为 `TP / targets`。
- 某类别的误激活图像是“不含该类别真值、但至少保留一个该类别预测”的图像；误激活率的分母是该类别的负样本图像数。
- mAP50 是按置信度排序后对 precision-recall 曲线积分的比赛指标，不等于下表单一运行点的 precision。

## 新增专家汇总

二类增量专家在逐类阈值后保留 264 个框：

- 正确匹配 87 个，错误检测 177 个，合并 precision 为 `87 / 264 = 0.329545`，recall 为 `87 / 87 = 1.000000`；
- patrol_boat 有 106 个 FP，armored_vehicle 有 71 个 FP；
- 按图像去重，共 58 张图至少发生一次新增类误激活，其中 5 张同时误激活 patrol_boat 和 armored_vehicle；
- 58 是错误图像去重数，177 是错误检测框数，两者含义不同。

这些诊断解释当前低阈值运行点的输出质量，但不改变比赛硬门禁结论：Base lock mAP50 `0.887550`、New-mAP50 `0.812249`、KRR `1.000000` 均已通过。
