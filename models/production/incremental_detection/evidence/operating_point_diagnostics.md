# strict 4+2 全类别抑制前运行点诊断

本文件保留引入全类别跨类别重叠抑制之前的冻结对照。该运行点使用 Scene-SensorNet 的实际场景概率与六类逐类训练先验做软阈值惩罚；Base 与 Increment 对每张图执行，线上输入为图像和场景模型概率。

当前正式结果在同一冻结模型和阈值上继续执行全类别重叠抑制，Base/New/KRR/Full-mAP50 为 `0.845782 / 0.750368 / 0.997179 / 0.800605`，见 [`all_images_diagnostics.md`](all_images_diagnostics.md)。因此下表的 `0.973126` 是历史抑制前运行点，不是当前 production KRR。
