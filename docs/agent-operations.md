# Agent 操作指南

## Web 工作台

环境配置完成后运行：

```bash
./scripts/start_agent.sh
```

浏览器打开 `http://127.0.0.1:8501`。Web 前端面向普通检测使用者，只包含：

- 智能检测：上传单张图像，自动识别传感器与场景，执行目标检测并导出标注图和 JSON。
- 自动能力编排：用户上传后，Agent 自动评估所有通过 New-mAP/KRR 门禁的增量能力；候选同时通过当前置信度阈值及与统一检测结果的空间一致性检查时自动融合，否则保持统一检测结果。场景认知只提供上下文，不作为固定激活限制。
- 批量检测：处理多张图像，在网页逐张选择和查看标注结果，并导出包含标注图和结构化结果的 ZIP。预览和下载地址临时保留30分钟，服务重启后失效。
- 任务记录：查看当前浏览器会话中的检测摘要，点击可跳回单图详情或批量逐张结果。完整结果只保留当前页面最近10份；页面刷新或缓存淘汰后，摘要仍保留并标记详情已过期。

界面的“纯推理时间”是本次参与模型各自 GPU 前向时间之和，包括上下文模型、基础检测器和 Agent 自动评估的类别专家；不包含上传、排队、图像预处理、框后处理、绘图和结果编码。模型并行时该数值表示计算量之和，不等同于关键路径时延。“系统总用时”从服务收到请求开始，统计到结果 JSON 构建完成，包含完整处理链路，是判断单请求速度的口径。

Web 使用本地 Starlette/Uvicorn 服务，图像仅在请求期间进入内存，不写入训练数据或固定报告目录。浏览器只在 `sessionStorage` 中保留最多20条轻量任务摘要，不保存图像与完整推理结果。Web 不显示权重哈希、模型指标、增量协议、门禁和审计细节；这些内容统一由 CLI 前端管理。

Web 输入与资源边界：

- 单文件不超过20MB，单张图像不超过2500万像素。
- 单批不超过20张且总大小不超过200MB。
- 重复内容由SHA256识别并拒绝，同名不同内容会生成不同任务ID。
- 所有浏览器会话共享公平的单GPU推理队列，避免并发调用同一模型实例。
- 当前会话只保留最近20条轻量记录；侧栏可一键清空图像结果和历史。
- 批量ZIP使用顺序号和原文件名组合命名，不会因同名文件覆盖。

## 终端工作台

SSH、无桌面服务器和未来板端环境使用：

```bash
./scripts/start_agent.sh --cli
```

该命令依次执行环境诊断、重建黑板并进入面向开发与运维人员的交互式 CLI 前端。它不会启动 Web 服务，也不会安装或修改依赖。

CLI 前端菜单：

```text
[1] 总览  [2] 模型  [3] 数据  [4] 增量  [5] 部署
[r] 刷新  [d] 决策  [p] Dry-run  [x] 执行  [q] 退出
```

`x` 只允许执行配置白名单中的低风险动作，并要求再次输入 `EXECUTE`。训练、正式推理和提交不会从 CLI 前端自动触发。

单独读取状态：

```bash
agile-agent status
agile-agent status --format json --refresh
agile-agent console --once
```

文本格式用于人工查看，JSON 格式用于外部守护进程、评测脚本或 AscendCL 服务集成。

## 审计运行

仅生成计划：

```bash
agile-agent pipeline --mode dryrun
```

执行允许列表中的低风险动作：

```bash
agile-agent pipeline --mode execute
```

每次运行写入独立的 `reports/agent_runs/<run_id>/`，包含计划、manifest、动作日志和 Markdown 报告。训练、正式推理与提交不由 v1 自动执行。

## Ascend 310B 边界

当前发布版本只验证 x86 NVIDIA GPU。production 默认使用 CUDA 版 PyTorch 直接加载仓库中的模型权重；TensorRT engine 不随仓库分发，只能在目标设备本地导出并单独验收。Python Agent 负责策略、审计和 Web 编排，`native/` 中的 C++ TensorRT ABI 仍为后续优化接口，尚未作为 production 后端。310B 状态固定为 `waiting_for_hardware`，后续必须依次完成：

1. 使用 ATC 将冻结模型转换为 OM。
2. 实现 AscendCL 输入预处理、推理和后处理。
3. 对齐 x86 与 310B 精度。
4. 在真实板卡上记录 FPS、时延和内存。

未完成上述门禁前，不得把 x86 GPU 指标作为 310B 性能证据。
